Lesson 1 · Build the model

Types, conversion, and user input

Every value has a type that determines what it represents and which operations make sense. Conversion lets input cross from text into numbers safely.

At a glance

  • Inspect common built-in types
  • Convert text into numeric values
  • Avoid combining incompatible types

Types describe meaning

Strings hold text, integers hold whole numbers, floats hold decimals, and Booleans hold True or False. type(value) reveals the current type.
